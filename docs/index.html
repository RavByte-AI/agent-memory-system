Repository memory

One command turns a codebase into agent-readable context.

The scanner detects manifests, routes, APIs, configs, tests, storage hints, docs, and generated directories, then writes deterministic Markdown plus a machine-readable topic index.

Automatic upkeep

Memory stays current as the repository moves.

`agent-memory maintain --since main` detects structural Git changes, refreshes the memory directory, and validates that agents have the latest project map.

Safe by default

Names, not secrets.

Environment variable names are documented, but secret values are blocked by validators. Generated and vendor directories are ignored as source ownership.

Cross-agent continuity

Antigravity starts it. Codex continues it. Claude reviews it.

Agent Memory System records checkpoints, commands, files, blockers, next steps, and final handoffs in `memory/agent-worklog.jsonl`, then generates `memory/agent-handoff.md` for the next assistant.
